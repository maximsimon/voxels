# Documentation

This documentation was last updated 29. 5. 2026 (all /docs file).
It may be incomplete and somewhere differing from code.
We do not update it vigorously.
However the documentation  is quite large and we hope you will find helpful info to most of what can happen.
The documentation contains both shorter, more concept oriented files and longer technical descriptions of code and architecture, so that you can read for understanding or search for keywords for troubleshooting.

**Note:** In more rigorous documentation files (index.md, api_reference.md, ...) some info can be inaccurate or have outdated values.
We recommend checking important info in the code.
Values of parameters in this documentation are meant more as an example. They may be outdated.

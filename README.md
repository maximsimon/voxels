# voxels
Rendering a voxel world using raylib.

Compile by `make` then run `voxel.o`.

Currently can generate voxel at given location and it can load pixel map and places voxel at each pixel - mazebuilding from image.

Collisions are not done.

DOCUMENTATION:

get\"fill-in\"Direction hazi 3D kriz se stedem v pocatku grid ale rotace je takhle: up a down jsou nahoru a dolu relativne ke grid, forward, back ,right adn left are relative to robots rotation.
